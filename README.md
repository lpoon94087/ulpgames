# ULP Games

Party games for phones: **https://lpoon94087.github.io/ulpgames/**

The start page lets you pick a game. Each game lives in its own folder and shares the code in `shared/`.

| Folder | Game | Devices |
| --- | --- | --- |
| `madgab/` | Mad Gab | 2 or more: a moderator and one or more viewers |
| `watch-ya-mouth/` | Watch Ya Mouth | 1, held by the reader |
| `password/` | Password | 1, or a moderator plus clue-giver and scoreboard screens |
| `word-generator/` | Word Generator | 1, or a moderator plus any number of viewers |
| `codenames/` | Codenames | 1+: the board on a big screen, the spymaster key on the spymasters' phones, synced through a room |

## Mad Gab

- **Moderator** — tap *Moderator*. You get a 4-letter room code and a QR code, pick the round length, Easy or Hard cards, and team names, then *Start game*. You see the puzzle and the answer, and tap **Got It** or **Skip**. With no viewer, tick *One phone: hide the answer until it's tapped*: the answer stays blurred, so the phone can be passed around and the reader sees only the puzzle. After each round, *Next round* shows whose turn it is with a single *Start round* button; the settings only change through *New game*.
- **Viewer** — scan the QR code, or tap *Viewer* and type the room code. The team sees only the puzzle, the clock and the scores. Answers appear on the viewer only when the round ends.
- **Menu** — tap *Mad Gab* in the top corner. The moderator gets *New game* (stops any round and sets every team back to 0), *Reshuffle deck* and *Leave game* (the viewer sees that the game ended); a viewer gets *Leave room*; the start page gets *How to play*. Every screen also has *Home*, back to the ULP Games start page (it asks first if a game is running), and *About*, which shows the version and card counts. The ULP Games start page has its own menu with *Reload*, which fetches the latest version: handy in a web app saved to a phone's home screen, which has no refresh button.
- **Demo** — tap *Try a demo* on the start page. It shows one example puzzle (*Olive Yew*), reveals the answer (*I Love You*), then explains the two roles.

Devices sync through rooms in a Firebase Realtime Database (project `madgab-b4a1e`); its rules are in `database.rules.json` and deploy with `npx firebase-tools deploy --only database`. Cards come from `madgab/flashcards.txt`, one per line as `puzzle,answer[,easy|hard]`. The level is optional and defaults to hard; answers may contain commas. Old room links (`/?join=CODE`) are forwarded to `madgab/`.

## Watch Ya Mouth

The reader wears a cheek retractor and reads each phrase out loud; their team has to work out what they're saying. One phone, held by the reader: set the round length and teams and tap *Start game*; the "you're up" screen comes first, so the reader can put the mouthpiece in, then *Start round*, then **Got It** or **Skip** for each phrase. Between rounds the phone goes to the next team's reader. Phrases come from `watch-ya-mouth/phrases.txt`, one per line.

## Password

Two teams of two. Both clue-givers see the secret word; the team shown as **guessing** gets a one-word clue and one guess. Wrong passes the next clue to the other team, and after 10 clues nobody scores the word. Teams take turns giving the first clue on each word. Two kinds of scoring:

- **Classic** — a word is worth 10, less one for every wrong guess; first to the target score (15–40, default 25) wins.
- **Simple** — every right answer is 1 point. Play 5, 10, 15 or 20 rounds; in each round both teams start one word, so it's even. Most points wins, and it can end in a tie. Skipped words don't count toward the rounds.

- **Moderator** — the room code and QR code, team names and target, then each word with its value and whose turn it is. *Got it* scores the word for the guessing team, *Wrong* takes a point off and switches teams, *Skip word* draws another, and *Undo* reverses the last tap (a second tap within half a second is ignored, so a double-tap on *Wrong* doesn't cost two points). The game and its undo history are saved, so a reload carries on, Undo included. Opening the game again in a new tab (or after a phone threw the tab away) asks *Carry on the last game?* with the scores and how long ago it was left, or *New game*; either way it opens the same room code as before (within 6 hours), so the TV and clue-giver screens pick up again.
- **Clue giver** — a read-only copy of the moderator's screen, word included, for the second clue-giver.
- **Scoreboard** — for the guessers: the points, the scores and a large banner in the guessing team's colour, never the word. Each screen in a room gets the same data; the scoreboard just doesn't show the word.
- The QR code opens a choice between Clue giver and Scoreboard, so a guesser who scans it doesn't see the word by accident.

Words come from `password/words.txt`: every one-word entry in the Word Generator's lists except movie titles.

## Word Generator

Words for Charades, Pictionary, describe-it games and anything else. Choose *Moderator*, tick the lists you want (any mix, such as *Pictionary: Easy* + *Animals* + *Food*; each family has an *All* toggle and there's *Everything*), then either:

- **Just words** — tap *Next word* whenever you need one. Each new word is covered until tapped (a setup option), so only the player holding the phone sees it. In a mix, each word says which list it came from and what to do with it.
- **Timed rounds** — the same teams, clock, Got It / Skip and results as the other games.
- **Moderator or Viewer** — like Mad Gab, the Word Generator opens on a choice: Moderator, Viewer or Scoreboard. The **Moderator** has every control and works fine as the only device; its setup screen shows a room code and QR code. A **Viewer** (scan the code, or tap *Viewer* and type it) shows the current word and its list, plus the clock, scores and results in timed rounds, and can't change anything. Viewers show the word even when it's covered on the moderator. *Leave game* in the moderator's menu ends the game on the viewers. A **Scoreboard** joins the same way but never shows the word: it shows a large clock and the scores, and after each round the words got and missed, so it can face the guessing team.

Words don't repeat until the chosen lists run out. The lists are `word-generator/lists/<id>.txt`, one word per line; `word-generator/lists.json` gives each its name, its group in the picker (*Games* or *Topics*), its family (lists in the same family are shown together under one heading with an *All* toggle; lists with no family go under their group) and the tip shown with it. To add a list, add a file and an entry. The lists were written for this site; the Pictionary and Charades lists also include words picked from the 12dicts word list (2of12), filtered to ones people know and can draw or act out. *Pictionary: Phrases* and *Charades: Phrases* hold two- to five-word phrases (things to draw, and actions such as "walking the dog") that aren't in any other list.

In a mix, every ticked list comes up about as often as the others, however many words it has, and a word that's in two lists ("duck" is in four) comes up once. *Single words only* leaves out phrases and long titles. In timed rounds, *Skips per round* can limit skips (1, 3 or 5), and the play screen shows each word's list with what to do ("Places · Draw it, act it or describe it"). A list file that fails to load is left out and named; the others still work.

## Codenames

Opens on a choice between **Board** and **Spymaster**.

- **Board** — for a TV or big screen. 25 words dealt from the word lists ticked on the start screen. The board knows the key, so when a team picks a card, it turns to its colour: grey (bystander), red, blue or black (assassin). As it turns, the board plays a sound: a rising chime for a red or blue agent, a soft bonk for a bystander and a falling buzz for the assassin (*Sound: on/off* in the board's menu). A few seconds later it shows a picture from `codenames/img/` (listed in `codenames/images.json`). Turning takes two taps: the first picks the card (it grows and gets a border), the second turns it. Moving the mouse off the card, or tapping anywhere else, lets it go, so a stray tap does nothing. The same two taps turn a turned card face down again. In the header, beside the title (its own header row on a phone): how many cards each team has left (a note for who went first and for the assassin is written but hidden for now; see `renderLeft` in `cn.js`). A reload keeps the game. `?addon=WORD,WORD` adds words to the pool; `?demo` turns a random card every second.
- **Spymaster** — the secret key card: a 5×5 grid with 9 cards for the team that goes first, 8 for the other team, 7 neutral (tan) and 1 assassin (black). The frame is red or blue for the team that goes first. Each square matches the board card in the same place, and gets a white dot once that card is turned. Under the key, *Show words* has boxes for Red, Blue and Other (the neutral and assassin cards; all ticked by default, remembered per phone). A ticked colour's squares show their board word, shrunk to fit (a two-word entry like SCUBA DIVER goes on two lines), so the spymaster doesn't have to match places against the TV; a turned card's word dims. *Tap the key to turn cards on the board* (off by default, remembered per phone) makes the key the board's remote: tap a place to pick it, tap it again to turn that card on every board in the room (or back face down), handy when the TV has no touchscreen. The board unlocks its sounds on its first tap anywhere, so cards turned from a phone still sound on the TV. *New game* is in the menu.
- **Finale** — when a game ends, every board screen in the room (not the spymaster phones) shows a big spinning, zooming banner: *RED WINS!* or *BLUE WINS!* (that team's last card turned, with confetti and a fanfare) or *ASSASSIN!* (a red glow and a shake). It shows only at the moment the game ends, not on a reload; *New game* or *Close* dismisses it. Turning the last card back face down carries on the game.
- **New game** (in the menu on either screen) — new words, a new key and every card face down, for every screen in the room.
- **Rooms** — every screen, board or spymaster, is in a room, shown as a 4-letter code in the top right with how many screens are in it. A screen starts in a random room of its own, so a game can start without typing anything. Tap the code (or *Room* in the menu) and type another screen's code to join its game: the room's board and key then show on this screen, and whatever the room is missing (a board, a key) this screen fills in. A board brings a key of its own, so it works with no spymaster phone in the room; a spymaster joining the board's room picks up that key. A reload goes back to the same room and game, as long as the screen was used in the last 6 hours; after that it starts fresh in a new room. The room dialog also shows a QR code: scan it with a phone's camera and the phone opens the spymaster key in that room (`codenames/?room=CODE#spymaster`); a link to a room that's gone opens a room of its own and says so. The start screen shows this screen's room code; its *New room* button (also in the room dialog) moves a screen to a fresh code at any time, taking its game along. Offline, each screen works on its own.

- **Word lists** — pick one main list on the start screen: *Original* (the 400 classic words) or *Extended* (935 words: the classic ones without countries, continents, landmarks, a few odd ones and the long ones, plus 563 more everyday words). Then tick any mix-ins to add their words to it: *Fun* (170 pop-culture words, fine for kids: movies, characters, brands, snacks, games and toys, internet words and silly ones) *After Dark 18+* (64 party and innuendo words for adults) and *Explicit 18+* (39 swear words and crude double meanings like COCK, DICK and TIT; pure swears are tagged `#swear`, so a board has at most one; no slurs). The 18+ packs are off unless ticked. A mix-in is a `lists.json` entry with `"mix": true`. Extended and the mix-ins keep to single words of at most 10 letters, so every card is easy to read. After the list (or the *One word per category* box below) changes, the next Board or Spymaster screen opened starts a new game with them, for its whole room. The lists are `codenames/lists/<id>.txt`, one word per line, and `codenames/lists.json` names them; to add a list, add a file and an entry. A word can have tags, as in `LONDON #city` or `WITCH #person #creature`: a board never gets two words that share a tag, so a spymaster can't clue two of them with "cities". The start screen's *One word per category* box (on by default) turns this on or off; off, the board is dealt at random like the boxed game. Either way, no two cards share a word: entries are split at spaces and hyphens, so ICE and ICE CREAM, or SPIDER and SPIDER-MAN, never land on one board; and no card's word (3 letters or more) starts or ends another's, so no SNOW with SNOWMAN, STRIP with STRIPPER or BAT with BATMAN (a word in the middle of another, like AIR in FAIRY, is fine). Both lists tag their cities (`#city`), space (`#space`: planets, comets and the like), animals whose main meaning is the animal (`#animal`), people, jobs included (`#person`), and fantasy creatures (`#creature`); the mix-ins add `#movie`, `#character`, `#brand`, `#snack`, `#internet`, `#toy`, `#gross` `#drink`, `#body` and `#swear`; words with a strong second meaning, like BAT, MOUSE, PILOT or KING, aren't tagged.

The board came from the stand-alone codenames repo, with its default picture set.

## Offline

After one visit with internet, every game works on one device with no connection: `sw.js` (a service worker) keeps a copy of the whole site, including the Firebase and QR code libraries. Rooms still need internet, so offline the moderator's room panel says *Offline* and a viewer waits until the device is back online. Pages come from the saved copy at once and are refreshed in the background, so a change shows on the next visit; the start page's *Reload* gets it right away.

`sw.js` lists every file it saves and a version made from their contents. `tools/stamp-sw.py` rewrites both; run it before committing (the local pre-commit hook in `.git/hooks/pre-commit` does it and stages `sw.js`). A new file the site serves is picked up as long as it is under `shared/` or a game's folder. Codenames' pictures are left out of the list (they're large) and are saved the first time a board shows them.

## Code

- `shared/common.js` — the round engine (`createRounds`: teams, scores, a shuffled deck saved on the device so cards don't repeat until you reshuffle, the clock, Got It / Skip, results). The deck remembers the cards already drawn by their text, so editing a card file keeps that history. Scores are saved on the device too, so *Start game* on the setup screen asks *Carry on the last game?* (showing the scores) or *Start from 0* when old scores are there. A second tap within half a second of a new card is ignored, so a double-tap can't score a card nobody saw. *Undo* on the play screen takes back the last Got It or Skip (the point comes off and that card comes back). On the round-over screen, tapping a word switches it between ✓ and ✗ and fixes the score. *Game ends* on the setup screen picks how a game finishes: never, first to 10, 20 or 30 points, or after 3, 5 or 10 rounds (a round is one turn for every team); the game ends only after a full round, so every team gets the same number of turns, and the round-over screen (and the viewers) then name the winner or the tie, with *New game* in place of *Next round*). The round in progress is saved too: a reload, or a phone throwing the tab away, comes back to the same screen within 15 minutes, with the clock still running from when the round started, the card and this round's results; a round whose time ran out meanwhile ends. While paused, Got It and Skip are off and the card is hidden. Scores stay with a team's place in the list, so renaming a team keeps its score. Options a game can turn on: `balanceBy` (each draw picks a group first, so small lists come up as often as big ones), `sameAs` (a word in two lists is drawn once) and an `optSkips` select (a skip limit per round); plus the menu, the About box, `ask()` (the yes/no box every game uses instead of the browser's `confirm()`, which can hide behind a full-screen page), beeps and the screen wake lock.
- `shared/rooms.js` — rooms for games with viewers (Mad Gab, Word Generator, Password): the device keeps the code it hosted for 6 hours, so a moderator coming back in a new tab gets the same code and the viewers reconnect; if the moderator's device drops off, the database marks the room `away` and the viewers say the moderator's phone has gone offline until it's back. On a big screen (1000px wide or more) the viewer's clock and card grow to fill it; the moderator claims a 4-letter code and sends what viewers should see; the viewer screen joins and shows it read-only. `shareRoom` is a room of equal devices that all show and change the same state, each updating only its own fields (Codenames' board and key). Each room is tagged with its game, so a code from one game can't be joined from another.
- `shared/style.css` — styles for every page.
- `<game>/index.html` and `<game>/<game>.js` — the game's screens and whatever is specific to it (Mad Gab's rooms and viewer, its demo, its Easy/Hard filter).

To add a game: make a folder with an `index.html` containing the `setup`, `ready`, `play` and `over` sections (see the element ids listed above `createRounds`), call `createRounds` with its cards, and add a card for it to the root `index.html`. Each game has its own `VERSION` in its JS file; bump it when you change the game.

To run locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
